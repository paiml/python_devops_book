## What the book covers

- Python foundations, command-line tools and the filesystem
- Linux utilities, package management, build systems, monitoring and automated testing
- Cloud computing, infrastructure as code, Kubernetes and serverless
- Machine learning operations and data engineering from a DevOps view
- Building, deploying and operating a machine learning project
